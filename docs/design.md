# 設計メモ

マインドマップの見た目で、2D ゲームのように歩き回りながら、友人と作業進捗・作業依頼・技術調査報告を共有する部屋。

## 方針

| 層 | 中身 | 同期 |
|---|---|---|
| 世界の状態 | ノード、親子関係、プロフィール | Yjs（CRDT）の差分ファイルを Google ドライブの共有フォルダに置く（時間差同期） |
| 足跡・最後にいた場所 | タイル単位の通過記録 | ユーザーごとの JSON を上書き保存 |
| プレゼンス（今後） | リアルタイムのアバター位置 | y-webrtc などで P2P（未実装） |

サーバーは置かず、静的サイトと Google ドライブだけで動く。

## 共有フォルダの中身

```
共有フォルダ/
  u_{userId}_{時刻}_{乱数}.bin   … Yjs の差分。各自が新規作成するだけ（上書きしない）
  fp_{userId}.json               … 足跡。本人だけが上書きする
```

- **書き込み**: ローカルで変更した分だけ（`origin !== REMOTE`）を `Y.mergeUpdates` でまとめ、新しいファイルとして作る。既存ファイルを上書きしないので、何人が同時に書いても衝突しない。
- **読み込み**: 未適用のファイルをすべて `Y.applyUpdate` する。CRDT なので順番は関係なく、同じものを2回適用しても結果は変わらない。
- **圧縮**: 自分のファイルが20個を超えたら、自分の分だけ1つにまとめる。新しいファイルを作ってから古いものを消すので、途中で失敗してもデータは失われない。他人のファイルは消さない（ドライブではファイルを消せるのは基本的に所有者だけ）。
- **未保存の退避**: 保存前の変更は localStorage に退避し、タブを閉じても次回に保存される。
- **ポーリング**: ドライブモードでは30秒ごと。ヘッダーの「同期」ボタンで即時同期もできる。

## データモデル（`src/model/world.ts`）

```ts
nodes:    Y.Map<nodeId, Y.Map<field, value>>   // フィールド単位でマージされる
profiles: Y.Map<userId, Profile>               // 各自が自分のキーにだけ書く
```

ノードのフィールドは `parentId, text, type, status, assigneeId, x, y, authorId, updatedBy, createdAt, updatedAt, lock`。

- ツリーは入れ子にせず `parentId` で表す。付け替えが1フィールドの更新で済む。
- **循環の解消**: 同時の付け替えで循環ができたら、循環中で ID が最小のノードをルート扱いにする。どのクライアントでも同じ結果になる。
- **親が削除された場合**: そのノードはルート扱いにする。
- **削除**: 子ノードは削除したノードの親につなぎ直す。
- 色や名前はノードに書かず、`authorId` から表示時にプロフィールを引く。名前や色を変えると過去の表示もすべて変わる。

### 種類

| type | 用途 | 追加フィールド |
|---|---|---|
| note | メモ | なし |
| progress | 進捗 | status |
| request | 作業依頼 | status, assigneeId |
| research | 技術調査 | なし |

## ロック（レベル1：協調的なロック）

- `lock: { by, at }` を付けると、ロックした本人以外はテキスト・種類の編集、移動、削除ができない。
- 子ノードの追加は誰でもできる（ロックされた調査報告に質問をぶら下げられる）。
- 解除できるのはロックした本人だけ。
- 制限は UI とモデルの API で行っているだけで、データの層では強制していない（共有フォルダに書き込める人なら改造したクライアントで書き換えられる）。友人間での利用を前提にした割り切り。
- 本当に強制したくなったら、ロックしたノードを本人だけが書けるフォルダの別ドキュメントに移す「レベル2」を検討する。

## 足跡（`src/model/footprints.ts`）

- 32px のタイル単位で、新しいマスに入ったときだけ `[最終時刻, 回数]` を記録する。
- 7日より古いマスは保存時に消す。
- 描画では、古いほど薄く、何度も通ったマスほど濃く大きくする。
- 同じファイルに最後にいた位置も保存し、他の人には半透明の「ゴースト」として表示する。

## 「前回以降の変更」

前回この部屋を離れた時刻を localStorage に覚えておき、それより後に他の人が更新したノードに NEW を付ける。

## 認証

- Google Identity Services のトークン方式で、ブラウザだけで完結する。アクセストークンは約1時間で切れ、切れたら「再ログイン」バナーを出す。
- スコープは `openid profile https://www.googleapis.com/auth/drive`。テストユーザーなら審査不要。
- 一般公開するなら、`drive.file` と Google Picker（共有フォルダを一度選んでもらう）への移行が必要。
